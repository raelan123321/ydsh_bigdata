## 项目目标

围绕云购生活新零售业务，搭建企业级数据仓库与经营分析可视化系统：

1. 完成大数据基础环境（Docker / Hive / MySQL）容器化搭建；
2. 将 6 张业务模拟数据（用户、商品、门店、订单、订单明细、用户行为）接入 ODS 贴源层；
3. 建立数据质量评估体系（完整性 / 唯一性 / 有效性 / 一致性 / 准确性五维度）；
4. 完成 DWD 明细层的数据清洗（缺失值填充、重复值去重）；
5. 后续周次逐步完成数据加工与经营分析可视化。

## 技术栈

- **容器化**：Docker Desktop + Docker Compose（MySQL 8.0 / Apache Hive 3.1.3）
- **数据仓库**：HiveServer2 + Hive Metastore（MySQL 元数据库）
- **数据处理**：Hive SQL（ODS 建表、LOAD DATA、窗口函数去重、缺失值填充）
- **版本管理**：Git + GitHub（feat:/fix:/docs: 提交规范）
