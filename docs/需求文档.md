# 需求文档

项目：云购生活新零售企业——企业级数据仓库与经营分析可视化系统　|　版本：v1.0（第 5 周整合）　|　状态：已交付

## 一、业务背景

云购生活是一家线上线下融合的新零售企业，销售触点覆盖 APP、PC 官网、小程序与线下门店四大渠道，经营食品生鲜、服饰鞋包、图书文娱、数码家电、运动户外等大类商品。随着业务规模扩大，经营数据分散在各业务系统中，管理层无法实时掌握整体经营状况，分析师依赖手工取数效率低下，业务人员难以直接使用数据。

为此，企业需要建设一套**端到端的企业级数据仓库与经营分析可视化系统**：以 2024 年全年真实业务口径的模拟数据为基础，完成「数据接入 → 质量治理 → 数仓建模 → 分析建模 → AI 集成 → 可视化展示 → 一键部署」的全流程能力建设。

## 二、干系人与核心诉求

| 干系人 | 核心诉求 | 承载功能 |
|---|---|---|
| 管理层 | 一屏掌握经营大盘，实时感知 GMV 与结构变化 | ECharts 经营数据大屏 |
| 数据分析师 | 自助式 BI，可自由探索品类/渠道/区域/时段 | Superset 仪表板 |
| 业务人员 | 用自然语言直接查询数据，无需写 SQL | Streamlit NL2SQL 智能问答 |
| 经营决策层 | 对未来销售趋势有量化预期 | GMV 预测模型 |
| 数据工程团队 | 系统可一键复现、密钥安全、文档齐全 | Docker Compose 编排 + 五大文档 |

## 三、数据范围

- 时间范围：2024-01-01 ~ 2024-12-31（全年 366 天）
- 数据源：6 张业务表——订单（15,600）、订单明细（37,549）、用户（1,000）、商品（600）、门店（60）、用户行为（60,000）
- 交付口径：源数据含五类脏数据，须经质量治理后进入数仓

## 四、指标体系定义（口径统一，全链路一致）

| 指标 | 口径定义 | 计算层 |
|---|---|---|
| GMV | 有效订单 pay_amount 之和（剔除待支付/已取消） | DWS→ADS |
| 有效订单量 | 状态为「完成/已付款」的订单去重计数 | DWD |
| 客单价 AOV | GMV ÷ 有效订单量 | DWS |
| 活跃用户数 | 统计周期内下单用户去重数 | DWS |
| 复购率 | 下单 ≥2 次用户数 ÷ 下单用户数 | ADS |
| 渠道销售占比 | 各渠道销售额 ÷ 全渠道销售额 | DWS |
| 品类销售占比 | 各大类销售额 ÷ 全品类销售额 | DWS |
| 区域销售分布 | 按省聚合的销售额与订单量 | ADS |
| 时段热力 | 星期 × 小时粒度的订单分布 | ADS |
| 平均优惠金额 | 折扣金额均值，监控让利水平 | DWS |

**基准值（验收锚点）**：GMV 23,290,536.89 元 / 有效订单 9,236 单 / AOV 2,521.71 元 / 活跃用户 1,000 人。

## 五、功能需求

1. **数据接入（ODS）**：6 张源表原样贴源接入，保留原始脏数据供质量审计。
2. **质量治理（DWD）**：缺失值、重复数据、异常值、枚举不规范、格式问题五类脏数据全部修复；维度建模（星型模型：订单事实 + 用户/商品/门店维度）。
3. **汇总建模（DWS）**：日/周/月/品类/门店/渠道六张聚合表，支持任意上卷分析。
4. **应用层（ADS）**：KPI 汇总与区域、用户价值等专题表，同步 MySQL 供应用消费。
5. **分析建模**：GMV 预测（多模型对比选优，输出未来 7 天预测）。
6. **AI 集成**：NL2SQL 自然语言问答（问题 → SQL → 执行 → 图表渲染闭环）、AI 智能洞察（异常归因）。
7. **可视化**：ECharts 大屏（KPI/趋势/品类/渠道/区域/热力/散点）+ Superset 仪表板。
8. **一键部署**：Docker Compose 7 服务编排，healthcheck 启动序，密钥环境变量注入。

## 六、非功能需求

- **性能**：接口 HTTP p50 ≤ 100ms（实测 28.5ms）；Hive 分区裁剪优化（实测快 22%）。
- **可复现**：`cp .env.example .env && docker compose up -d` 即可启动；Hive 元数据幂等初始化，重启不死循环。
- **安全**：数据库密码、Superset 密钥等全部经 `.env` 注入，代码零硬编码。
- **可维护**：SQL 按 ods/quality/clean/dwd/dws/ads 六层目录组织；文档齐全可追溯。

## 七、验收标准

1. 各层行数与指标值逐层吻合（见《第5周_联调核对清单》，18 项全过）。
2. 五类脏数据修复率 100%，可由质量 SQL 复核。
3. 大屏/仪表板/问答/预测四个应用端到端可用。
4. `docker compose up -d` 一键启动后全部服务健康。
