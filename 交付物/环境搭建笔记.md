# 第 1 周环境搭建笔记

- 记录人：刘正扬　日期：2026-10-30
- 环境：Windows 11 + WSL2 + Docker Desktop（Docker 29.9.2 / Docker Compose v5.6.1）

## 一、搭建过程

### 1. Docker Desktop 安装

1. 从 Docker 官网下载 Docker Desktop for Windows，安装时勾选 **WSL 2 backend**；
2. 安装完成后重启电脑，启动 Docker Desktop；
3. 验证：

```powershell
docker --version          # Docker version 29.9.2
docker compose version    # Docker Compose version v5.6.1
```

### 2. 编写 docker-compose.yml 启动 Hive + MySQL

在项目根目录编写 `docker-compose.yml`，编排三个服务：

- **mysql**（mysql:8.0）：作为 Metastore 元数据库，配置 `MYSQL_DATABASE: metastore_db`，并加 **healthcheck**（`mysqladmin ping`）保证元数据库就绪后才启动 Metastore；
- **hive-metastore**（apache/hive:3.1.3）：`depends_on: mysql (service_healthy)`，通过环境变量指定 JDBC 连接 MySQL；
- **hive-server**（apache/hive:3.1.3）：`SERVICE_NAME: hiveserver2`，暴露 10000（JDBC）/ 10002（Web UI）端口。

启动与验证：

```powershell
docker compose up -d
docker ps    # 应看到 mysql、hive-metastore、hive-server 三个容器均为 Up
```

### 3. 连接 Hive 验证

```bash
docker exec -it hive-server beeline -u jdbc:hive2://localhost:10000
show databases;
create database if not exists ydsh_ods;
```

## 二、遇到的问题与解决

| 问题 | 现象 | 解决方案 |
|---|---|---|
| Hive 服务启动顺序 | Metastore 未就绪时 HiveServer2 起不来 | compose 中用 `depends_on` + `condition: service_healthy` 保证 MySQL 健康检查通过后再启动 Metastore |
| CSV 表头被当成数据导入 | 导入后第一行变成字段名 | 建表时加 `tblproperties('skip.header.line.count'='1')` |
| CSV 日期格式混乱 | 同一列混用 `2024-07-26` 与 `2024/09/10` 两种格式 | 预评估统计出问题行数（订单表 1902 条），后续清洗阶段统一为 `YYYY-MM-DD` |
| DWD 数据库创建权限报错 | Hive 默认 warehouse 路径无写权限 | 建库时显式指定 `location '/opt/hive/ydsh_dwd'` 解决 |
| 数据文件路径 | `load data local inpath` 的路径是容器内路径 | 将 CSV 放入容器可见目录后再加载，导入后用 `count(*)` 与预期行数逐一校验（1000/600/60/15600/37549/60000） |
