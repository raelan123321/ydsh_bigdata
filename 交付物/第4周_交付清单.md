## 二、各子任务实现说明

### 子任务 1：Superset 仪表板（25 分）

| 图表 | 数据集 | 类型 |
|------|--------|------|
| 月度 GMV 趋势 | ads.ads_sales_daily | 折线（时间序列） |
| 品类销售额 Top10 | ads.ads_category_top10 | 柱状 |
| 区域销售额排行 | ads.ads_region | 横向柱状 |
| 渠道销售占比 | ads.ads_channel | 饼图 |
| 用户价值分层 | ads.ads_user_value | 柱状（RFM） |

- 数据源：Hive（`hive://hive@hive-server:10000/default`）+ MySQL（ADS 结果库 `ydsh_ads`）
- 自动化：REST API 建库连接 → 数据集 → 图表 → `position_json` v2 布局组装 Dashboard
- 验证：SQL Lab 查询 `ads.ads_region` 返回 15 行，Superset→Hive 连通正常
- 说明：Superset 3.x 对中国省级地图支持弱，区域维度用「省份排行柱状图」呈现，真·地图放在 ECharts 大屏

### 子任务 2：ECharts 数据大屏（25 分）

- 设计稿 1920×1080，`scale = min(w/1920, h/1080)` 整体缩放，任意屏幕不错位
- 六类图表：月度 GMV 双轴折线、品类 Top10 渐变柱状、渠道玫瑰饼图、区域地图（GeoJSON 中国地图）、时段×品类热力图、GMV-订单量散点
- 数据接口 `GET /api/all` 一次返回 7 组 JSON；`gen_data.py` 从第 3 周 KPI 结果与模拟明细预生成（热力图按「时段×品类」从订单明细实时聚合）
- 离线可用：ECharts 与 GeoJSON 均本地化，不依赖外网 CDN

### 子任务 3：Streamlit 智能问答（20 分）

- 链路：提问 → NL2SQL.generate（LLM 或规则兜底）→ guard 只放行 SELECT 并自动补 limit → pyhive 执行 → DataFrame 展示 → 按结果形状自动推荐折线/柱状图（ECharts 内联渲染）
- 交互：侧栏示例问题、历史对话、加载状态（spinner）、中文错误提示、清空按钮
- 降级：未配置 `LLM_API_KEY` 时自动走规则兜底，闭环不中断；实测「2024年7月GMV」「各渠道销售额占比」两问结果与 KPI 表勾稽一致

### 子任务 4：Docker Compose 一键部署（20 分）

| 服务 | 端口 | 说明 |
|------|------|------|
| mysql | 3306 | Hive metastore 元数据库 + ADS 结果库 |
| hive-metastore | 9083 | 元数据服务 |
| hive-server | 10000 / 10002 | HiveServer2 |
| superset | 8088 | BI 仪表板（自建镜像，内置 pyhive） |
| clickhouse | 8123 / 9000 | OLAP 预留 |
| screen-api | 8080 | 大屏 JSON 接口 + 静态页 |
| app | 8501 | Streamlit 问答 |

- 启动顺序：`depends_on` + `healthcheck`（mysql healthy → metastore → hive-server → superset/app）
- 密钥：全部 `${VAR}` 引用，真实值只存本地 `.env`（已 gitignore），模板入库 `.env.example`

### 子任务 5：密钥安全 / 查询优化 / 压测

| 场景 | 样本 | p50 | p95 | 结论 |
|------|------|-----|-----|------|
| Hive 分区裁剪（2024-11） | 9 | 1.12 s | 1.28 s | 较全表快约 22% |
| Hive 全表扫描（同条件） | 9 | 1.42 s | 1.56 s | 基线 |
| HTTP `GET /api/all`（并发 10） | 30 | 28.5 ms | 170 ms | 约 14.3 QPS |

优化措施：分区裁剪（`where order_date between`）、ADS 层 ORC 存储、高基数 key（user_id）加盐打散、Tez 单次扫描减少 Shuffle。

## 三、环境与验证方式

```bash
# 一键启动
cp .env.example .env          # 按需填密钥
docker compose up -d
docker compose ps             # 期望 7 个服务 Up/healthy

# Superset 初始化（首次）
docker exec superset superset db upgrade
docker exec superset superset fab create-admin --username admin \
  --firstname Admin --lastname User --email admin@example.com --password admin
docker exec superset superset init
python python/superset_setup.py       # 自动建连接/数据集/图表/Dashboard

# 访问
# Superset  http://localhost:8088 （admin/admin）
# 数据大屏  http://localhost:8080
# 智能问答  http://localhost:8501
# ClickHouse http://localhost:8123
```
