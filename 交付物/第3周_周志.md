# 第 3 周实训周志

**题目：从明细到洞察——汇总建模、智能问答与团队协同**

本周聚焦数据仓库的汇总层与应用层建设。基于 DWD 明细数据搭建了天/周/月、品类、门店、渠道六个维度的 DWS 汇总表，并在 ADS 层落地销售日报、品类 Top10 与用户 RFM 分层模型，计算出 GMV、客单价、活跃用户数等五项核心经营指标。随后开展 GMV 预测建模，对比均值基线、移动平均与线性回归三种方案，发现数据无明显趋势与季节性，最简单的均值基线反而效果最优，让我体会到模型选择应尊重数据本身而非盲目追求复杂。本周还搭建了 NL2SQL 智能问答链路，实现自然语言到 SQL 的自动生成、安全校验与执行评测，并完成 AI 智能洞察报告，定位了异常波动的归因线索。团队通过 Git 分支协作完成 PR 与 Code Review，工程规范意识明显提升。
