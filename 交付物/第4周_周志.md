# 第 4 周实训周志

**题目：让数据开口说话——可视化大屏与一键部署**

本周进入成果可视化与系统部署阶段。我用 Apache Superset 连接 Hive 与 MySQL，基于 ADS 层指标表制作了销售趋势折线图、品类柱状图、区域地图、渠道占比饼图和 TopN 排行表五类图表，并通过筛选器实现了仪表板联动。同时用 ECharts 开发经营数据大屏，实现折线、柱状、散点、热力、地图五类图表，采用 scale 整体缩放方案完成 1920×1080 设计稿的多分辨率自适应。我还把上周的 NL2SQL 后端接入 Streamlit，打通了"提问→生成 SQL→执行→图表渲染"的智能问答闭环。工程侧编写 Docker Compose 编排文件，将 MySQL、Hive、Superset、ClickHouse 与应用服务一键拉起，通过环境变量注入密钥、配置健康检查，并完成查询分区优化与并发压测。本周让我体会到，数据价值只有变成看得懂、用得稳的系统，才算真正落地。
