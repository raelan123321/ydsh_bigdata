## 四、联调中已修复的问题（本周解决）

1. **Hive 容器重启死循环**：官方镜像 entrypoint 每次启动无条件 `initSchema`，Derby 元数据已存在即失败。→ 自建镜像 `w4-hive`，幂等初始化 + 元数据/仓库命名卷持久化。
2. **HS2 健康检查失败**：HiveServer2 只绑定容器 IP。→ `hive.server2.thrift.bind.host=0.0.0.0`。
3. **覆盖镜像默认配置丢失 Tez**：整文件替换 hive-site.xml 导致执行引擎退回 MR。→ 改为「默认项 + 增补」合并版。
4. **仓库文件残留导致数据翻倍**：`drop database` 不删 HDFS 文件。→ `drop ... cascade` + 清空 warehouse 目录后再灌。
5. **Superset 管理员丢失**：镜像重建重置元数据库。→ 重新 `create-admin` + 脚本化重建数据源/图表/仪表板。
