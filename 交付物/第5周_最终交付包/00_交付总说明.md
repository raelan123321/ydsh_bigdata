## 交付物 1「可运行系统」启动说明

系统本体即 GitHub 仓库（完整代码：sql/ python/ app/ hive/ superset/），本包收录一键启动所需的编排文件。在装有 Docker Desktop 的机器上：

```bash
git clone https://github.com/raelan123321/ydsh_bigdata
cd ydsh_bigdata
cp .env.example .env          # 按需修改密钥（有默认值可直接用）
docker compose up -d          # 一键拉起 7 个服务
```

启动后约 2~3 分钟就绪，验证入口：

| 应用 | 地址 | 说明 |
|---|---|---|
| ECharts 数据大屏 | http://localhost:8080 | KPI 卡片 + 趋势 + 排行 + 热力图 |
| Superset 仪表板 | http://localhost:8088 | 账号 admin / admin，5 张图表直连 Hive |
| Streamlit 智能问答 | http://localhost:8501 | NL2SQL 三问演示 |

核心指标基准（供核对）：GMV 23,290,536.89 元 / 有效订单 9,236 单 / 客单价 2,521.71 元 / 活跃用户 1,000 / 月度复购率 28.68%~34.31%。

> 数据重灌（如需从零复现）：容器内依次执行 `output/hive_demo/` 与 `sql/` 下 12 个脚本，详见部署手册第六节。
